# 游学/留学机构合规数据管理系统（演示 · 菲律宾游学专线）

基于国务院令第841号（出入境中介双重备案）、教基一〔2016〕8号（研学行前备案）、
PIPL / 网安法（2025修正）/《未成年人网络保护条例》实现的机构自用数据管理系统演示。
主故事线为**菲律宾游学中介**（团体 Junior Camp + 个人语言研修双形态），业务闭环与合规动作双线并重。
**全部数据为虚构示例；学校名为公开信息，价格为演示虚构值，不含任何真实个人信息。**

调研依据见 `research/01~04` 报告（04 为菲律宾游学实际业务调研），设计见 `docs/design.md`。

## 快速开始

```bash
uv sync                                  # 安装依赖
uv run alembic upgrade head              # 建表
uv run python scripts/seed.py            # 幂等种子数据（虚构）
uv run uvicorn app.main:app --port 8120  # 启动
# 浏览器打开 http://127.0.0.1:8120/
```

## 功能地图

| 模块 | 能力 | 法规/业务锚点 |
|---|---|---|
| 机构档案 + 人员备案 | 841号令双重备案要件（无犯罪声明/场所证明/五项制度） | 841号令 |
| 学校库 + 课程价目 | 地区/风格（斯巴达等）/佣金率/注册费/**合作协议**（备案要件）；课程按周计价、房型差价、保分条款 | 841号令；菲律宾按周计费惯例 |
| 报价单 | 选校→课程→周数→房型实时算价（学费/注册费/当地费PHP预估/返佣预估）；草稿→发送→**确认转报名**（一个事务） | 真实中介「免费测试→出方案→比价」流程 |
| 学员主索引 | student_no 唯一标识 → 360 归集（报价/报名/合同/缴费/周报/服务节点/同意书）+ 审计溯源计数 | 校外培训监管平台实践 |
| 同意管理 | 监护人分项单独同意（**项目级或机构通用**）、可撤回、撤回即拦截新报名 | PIPL 第29/31条 |
| 活动备案 | 行前备案≥30日、出境资质/2国4城/时长/师生比1:10/保险/应急预案（团体营）；**语言研修个人计划免备案**，校验周数≥课程最短/房型在价目表内 | 教基一〔2016〕8号、LB/T 091-2025 |
| 菲律宾行政链 | 报名校验：护照≥离校后6个月、未满15岁须 **WEG/监护同行证明**；推进「在读」须 **SSP**，课程>59天还须 **ACR I-Card** | 菲律宾移民局规则（research/04） |
| 在读周报 | 分班测试（W0）+每周等级/模考/出勤/教师评语/家长反馈时间 | 保分班97%出勤、家长群报实践 |
| 合同与资金 | 游学服务协议（USD/CNY 口径）+ 退费双轨预设（**菲律宾学校梯度**/GF-2016-1002）+ 试算；缴费区分定金/学费/注册费/当地费 × **CNY/USD/PHP** 三币种代收代缴凭证链 | I.BREEZE式退费条款；79号令 |
| 审计留痕 | 全写操作追加写 + SHA-256 哈希链 + /api/audit/verify 篡改检测；报价确认/作废同样入链 | 网安法第23条、条例第36条 |
| 业务看板 | 在读学员/待跟进报价/本月入学/预计佣金（内部） | 中介「零服务费+学校返佣」模式 |
| 保存年限 | 日志2年/PIA 3年/留学合同5年/合同凭证30年 | 见 /api/meta/retention |

## 已知边界（演示定位）

- 无登录认证（写操作以"演示管理员"留痕，接口层已预留 actor）
- 单机构单机 SQLite（WAL），迁 PG 可用 pgloader
- 监管报送为数据导出能力预留，未做自动报送
- SSP/ACR 校验仅对「语言研修 + 菲律宾学校」生效（团体营多目的地，SSP 非普适）
- 佣金为内部核算展示，未做中介-学校间结算流程

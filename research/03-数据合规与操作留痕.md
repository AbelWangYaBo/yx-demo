# 教育游学机构数据管理系统：数据合规与操作留痕法规依据（截至2026-11）

> 适用对象：对外游学/留学机构数据管理系统。核心诉求：① 操作留痕可审计；② 按学员标识检索全部记录；③ 满足备案监管要求。以下条文均经来源核实（国家网信办/中国人大网、政府官网、教育部官网文本）。

## 一、个人信息保护法（PIPL，2021-11-01施行）关键义务

- **未成年人信息=敏感个人信息（第28条）**：敏感个人信息包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，**以及不满十四周岁未成年人的个人信息**；仅可在特定目的、充分必要并采取严格保护措施时处理。
- **监护人同意与专门规则（第31条）**："个人信息处理者处理不满十四周岁未成年人个人信息的，应当取得未成年人的父母或者其他监护人的同意""应当制定专门的个人信息处理规则"。游学学员多为未成年人，系统必须内置监护人同意管理。
- **告知义务（第17条）**：处理前须显著、清晰告知：处理者名称和联系方式；处理目的、方式、信息种类、**保存期限**；个人行使权利的方式和程序；事项变更须再次告知；以处理规则方式告知的，规则应公开、便于查阅和保存。
- **敏感信息单独同意（第29条）**："处理敏感个人信息应当取得个人的单独同意"——不得以一揽子隐私政策概括授权替代。
- **影响评估与记录保存（第55、56条）**：处理敏感个人信息、自动化决策、委托处理/对外提供/公开、跨境提供等五类情形须**事前**做个人信息保护影响评估（PIA）；**评估报告和处理情况记录应当至少保存三年**。
- **安全事件通知（第57条）**：发生或可能发生泄露、篡改、丢失，应立即采取补救措施，并**通知履行个人信息保护职责的部门和个人**。
- **自动化处理（第24条）**：利用个人信息进行自动化决策应保证透明度和结果公平公正，不得对个人在交易价格等条件上实行不合理差别待遇。
- **安全制度（第51条）**：对个人信息实行分类管理、加密/去标识化、合理确定操作权限、定期教育培训、制定应急预案。违反义务最高可处5000万元或上年度营业额5%罚款（第66条）。

## 二、网络安全法：日志留存与等级保护

**注意：网络安全法已于2025-10-28修正（主席令第61号），自2026-01-01施行，原第21条内容现调整为第23条。** 现行文本原文：

> "国家实行网络安全等级保护制度。网络运营者应当按照网络安全等级保护制度的要求，履行下列安全保护义务……（三）采取监测、记录网络运行状态、网络安全事件的技术措施，**并按照规定留存相关的网络日志不少于六个月**；（四）采取数据分类、重要数据备份和加密等措施……"

- 系统须内置不可篡改的审计日志模块，日志在线留存≥6个月。
- **等保定级惯例**：教育移动应用提供者被要求完成ICP备案和**等级保护备案**（《教育移动互联网应用程序备案管理办法》教技厅〔2019〕3号，未完成将被撤销备案）；面向未成年人、处理大量个人信息的教学管理类平台，行业普遍按**第二级**定级备案，跨省服务或数据规模大的平台按**第三级**。未履行等保义务可依新法第61条处罚（最高50万元）。

## 三、数据安全法：分类分级与重要数据

- **第21条**：国家建立数据分类分级保护制度，按"重要程度＋危害程度"分类分级；国家数据安全工作协调机制统筹制定**重要数据目录**；关系国家安全、国民经济命脉、重要民生、重大公共利益的数据属**国家核心数据**，实行更严格管理。教育主管部门承担本行业数据安全监管职责。
- **重要数据识别**：《网络数据安全管理条例》（国务院令第790号，2025-01-01施行）第29条要求各地区各部门确定本行业重要数据具体目录，第62条给出重要数据定义；识别可依据GB/T 43697-2024《数据安全技术 数据分类分级规则》。游学机构的学员及家长信息一般不属重要数据，但应完成内部分类分级（如：身份/健康/行踪=敏感级，合同财务=重要级），留存定级记录备查。

## 四、教育行业专项规定

- **《未成年人网络保护条例》（2024-01-01施行）第四章"个人信息网络保护"（第31–38条）**：第31条实名信息要求；第32条不得强制同意非必要处理、不得因拒绝/撤回同意拒供基本服务；第34条保障未成年人及其监护人查阅、复制、更正、补充、删除权；**第36条最小授权——工作人员访问未成年人个人信息须经负责人审批并"记录访问情况"**；**第37条每年对未成年人个人信息处理合规情况进行审计**；第35条泄露通知。
- **《儿童个人信息网络保护规定》（网信办令，2019-10-01施行）**：儿童=不满14周岁；须设**专门儿童个人信息保护规则、用户协议并指定专人负责**；以显著清晰方式告知监护人并征得**明示同意**，同时提供拒绝选项；**加密存储**；访问须审批并**记录访问情况**；委托/转移第三方须安全评估；监护人撤回同意、停止运营等情形应删除；泄露须报告主管部门并告知监护人。
- **教育部等八部门《关于引导规范教育移动互联网应用有序健康发展的意见》（2019）**：教育移动应用须备案，收集使用个人信息应征得监护人同意授权，不得以默认、捆绑、停止安装等变相强迫授权，不得收集与服务无关的个人信息；采集人脸等生物识别信息需组织科学性、伦理性、安全性论证（北京等地入校管理规定进一步明确）。

## 五、业务留痕的行业实践与依据

- **合同与收费**：使用教育部、市场监管总局《中小学生校外培训服务合同（示范文本）》（2021修订版）；一次性收费不得超过3个月或60课时且不超过5000元，**预收费全额进入银行托管账户**，"一课一消"。
- **监管平台实践（学员主索引的行业范本）**："全国校外教育培训监管与服务综合平台"＋"校外培训家长端"App（2023年上线，家长端下载量超千万，合规机构12万余家）按学员归集：机构资质、电子合同（含学员信息、课程、付款信息）、缴费与消课记录、考勤与学习进度、评价与投诉，全流程线上可追溯；未在平台注册或未通过平台收费即属违规。这正是"按学员唯一标识归集全部记录＋操作留痕"的官方实践。
- **财务留痕年限**：《会计档案管理办法》（财政部、国家档案局令第79号，2016施行）：原始凭证、记账凭证等**最低保管30年**（电子会计档案同等效力）；合同、发票及退费凭证作为会计资料归档时适用30年，为系统中"合同/财务记录保存策略"的最硬性依据。

## 六、法规→系统功能映射表

| 法规条款 | 系统需实现的功能 |
|---|---|
| 网安法（2025修正）第23条第(三)项 | 操作/网络审计日志模块，日志留存≥6个月、防篡改 |
| 网安法第23条第(四)项、数据安全法第21条 | 数据分类分级打标、重要数据识别申报、备份与加密 |
| 等保备案惯例（教技厅〔2019〕3号） | 系统定级备案（建议二级及以上）、等保测评整改 |
| PIPL第17条 | 隐私告知/处理规则公示（含保存期限），版本留痕 |
| PIPL第28/29/31条 | 未成年人识别（按出生日期）+监护人同意管理+专门儿童处理规则+敏感信息单独同意 |
| 未成年人网络保护条例第34条、儿童规定 | 学员/监护人查询、更正、删除、撤回同意的请求处理流程 |
| 未成年人网络保护条例第36条、儿童规定 | 最小授权+数据访问审批流+访问记录日志 |
| 未成年人网络保护条例第37条 | 年度未成年人个人信息合规审计模块 |
| PIPL第55/56条 | PIA事前评估工作流，评估报告与记录保存≥3年 |
| PIPL第57条、儿童规定、条例第35条 | 安全事件应急预案与通知/报告生成 |
| 教育部八部门意见、各地教育App规范 | 备案信息管理（ICP/等保/教育App备案）、生物识别采集论证记录 |
| 《中小学生校外培训服务合同（示范文本）》、预收费监管 | 电子合同管理、学员唯一标识主索引（合同-课程-缴费-消课-考勤-投诉归集） |
| 会计档案管理办法（79号令） | 合同/凭证/账务记录保存≥30年的保存年限策略 |
| 网络数据安全管理条例第9/29条 | 数据安全管理制度文档、年度风险评估记录 |

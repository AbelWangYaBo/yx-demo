# 调研报告 04：菲律宾/东南亚游学英语培训实际业务（2026-11）

来源：两轮联网调研（学校侧业务 + 中国中介侧操作），关键数字均标注来源；
标「估计」者为多来源推断区间。价格为公开市场行情，系统中仅作演示参考值。

## 1. 市场与商业模式

- 菲律宾约 100 所语言学校，韩资约八成；对学员「零中介费」（与学校官方同价甚至低 5-15%），
  中介收入来自学校返佣 **20-40%**（台湾市场口径，大陆估计同量级）。
- 大多数学校不受理学员直接报名，只走合作中介通道——中介的结构性存在原因。
- 2026-09-15 施行的国务院令第 841 号：代办签证/证件/出入境咨询收费的中介必须备案，
  备案要件含「与境外服务机构的合作协议」；境外机构不得在境内直接提供出入境中介服务。

## 3. 课程与定价（按周计费，学费+住宿+三餐打包）

- 课时结构 = 1对1 + 团体课组合：如 ESL 一般 4:4、斯巴达密集 5:2+夜课、EV 密集 6:2。
- 行情：课程费 **USD 175-275/周**（含食宿，按房型）；注册费一次性 **USD 100-200（不退）**。
- IELTS/TOEIC 保分班：最短 8-12 周起（多数 12 周），保分机制=未达约定分数免费延长就读，
  附加条件出勤率 **97-100%** + 模考全勤。
- Junior Camp 冬夏令营：7-15 岁，3-4 周，全含价约 USD 2,800-3,500。
- 房型差价：1人间比 2-4 人间每 4 周贵 USD 150-400（估计区间）。
- 总预算参考（含机票杂费）：4 周 ¥1.2-2.5 万；12 周 ¥2.8-5.2 万。

## 5. 中介操作全流程（南崎/比顿/PECA 公开流程交叉）

咨询（微信/电话/转介绍）→ 免费水平测试（15 分钟 CEFR）→ 方案报价（1-3 天，多轮比价）
→ 签《游学服务协议书》+ 定金锁床位 → 学校 1-3 个工作日出 **LOA（录取通知书）+ INVOICE**
→ 凭 LOA 办签证 + 订机票 + 保险 → 学费尾款（USD 电汇，出发前 4-8 周；也有到校后付模式）
→ 行前说明会（eTravel/电话卡/换汇/行李）→ 周日接机到校 → 周一分班测试 + 缴当地费 + 办 SSP
→ 在读跟踪（成人：投诉受理/代缴费；青少年营：1:10 领队 + 每日家长群报 + 手机统一保管）
→ 毕业测试/成绩单 → 周六离校 → 归国（押金退还/成绩单代领）→ 复购/转介绍。

咨询到出发标准周期 30-45 天；旺季（寒暑假）提前 2-3 个月。

## 6. 退费真实条款（学校侧，I.BREEZE/HELP/SMEAG 交叉）

| 距开课 | 退费 |
|---|---|
| ≥4 周 | 扣注册费（USD 100-150，一律不退），余款全退 |
| 2-4 周 | 扣注册费 + 2 周住宿费 |
| 1-2 周 | 扣注册费 + 4 周住宿费 |
| <1 周 | 扣注册费 + 4 周学费+住宿费 |
| 在读重大疾病（凭证明） | 退剩余学费+住宿的 50% |
| 提前毕业/被开除 | 不退 |
| 不可抗力 | 不退、不赔（行业惯例） |

中介侧因零服务费，学校退费直接退学员本金；拒签无单列条款，按「出发前取消」梯度处理。

## 7. 家长/学员核心关切

安全（封闭校园/24h警卫/门禁）、医疗（私立医疗贵，必须含海外医疗的保险）、
效果（入学/毕业测试对比 + 每周模考 + 保分承诺）、退费（签约时逐条确认梯度）。
